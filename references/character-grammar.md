# Character Design Grammar · 1.29.1

身份来自真实动物特征的组合，人物来自持身、注意力、物件使用、衣物与生活习惯的可见关系。可爱不能只写成形容词，也不等于大眼短嘴、小头或小爪。允许动物自然结构、适度不对称与拘谨；不允许断尾、穿纸或不可信支撑。

Character Plan保留role、facial_character、charm_contrast、character_silhouette、action_design、paw_prop_roles、posture、gaze、clothing_response、animal_traits、visible_character_hook。补充identity_anchors、clothing_options、clothing_choice_reason、reference_inputs与user_request。无衣/用户指定衣物时说明依据，不机械造候选。无道具可通过具体持身形成状态，闭眼/非对视服从用户。

服装选项说明生活语境、领口、肩袖、松量、下摆、体积与毛色关系。宽松衣物可以包住身体，袖口可以连接上臂与爪；不能以旧版“所有袖子都粗”禁掉短袖。衣物图案是可选叙事线索，不复制样例标志。

原作反例：Lover的密织与眼口/衣体/小爪同时工作；Me Time的衣领袖口书与后靠关系说明状态；Son of Cod的小头长身与小爪可以成立。仅作为关系依据，不固定比例。
