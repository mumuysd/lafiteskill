# 1.29.1视觉验收

先正常大小整幅，看身份、人物、生活关系与主要明暗色形；再看眼口、衣物转面、爪物接触、尾与身体、承重及边缘；最后回整幅。缩略图可读不等于完成。

保留overall_review三维：character_presence（个体与生活行为/持身是否共同成立）、painting_organization（方向笔、形色、体积、边缘/对比是否组织注意力）、sitter_space_relationship（连接、遮挡、接触、支撑和裁切）。保留checks七项：identity、anatomy、paint_construction、scene、clothing、anthropomorphic_pose、facial_intention。

每项记录实际可见证据。身份核对该主体的特征组合，服装核对人物语境与领袖/腹部/动作；眼神核对可见注意力，不用标题补心理。细毛、自然鼻口、亮点、密织或厚笔不是单项fail理由；简化、少细节也不自动pass。背景有笔触仍可退后，若其对比、边缘或材料描绘压过人物，说明具体位置和作用。

与认可图比较“身份与表情是否具体、动作接触可信、衣物如何塑体积、描绘层级是否支撑人物”，不要求相同构图、颜色、笔痕密度或身材。用户认可独立true/false/null，不能因用户认可就把所有旧检查改pass；历史初次评审与本轮复核并存。关键fail/uncertain本例仍不通过；衣物无衣按原话waived。结构检查只验证格式、版本、来源、hash、计数和记录一致性，不打艺术分。

实际调用失败保存错误后停止，无新授权不生成或编辑。认可后单项改衣/改画法应检查原本认可的脸、姿态、尾、物件、支撑是否漂移。
