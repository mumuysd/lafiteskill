character-plan.json 与 composition-intent.json 是基于已运行餐巾猫构思整理的**虚构主体、离线组装示例**。没有调用生成工具，也没有配套“生成成功”图片。真实宠物使用时必须换入用户照片并核对身份，不能沿用 identity_waiver。

在仓库根目录运行 README 的组装命令，输出到 output/；脚本产出可核对的 prompt/trace/request，不含生成行为。
