# 本地发布候选与公网步骤

本目录是独立仓库根目录，复制后无需私人研究库。代码与文档 MIT，图像单独授权；详见 LICENSE 与 assets/ASSET-LICENSE.md。

已完成：相对路径、无覆盖安装、十四项离线回归、认可资产 hash、本地链接、私人路径与明显凭据检查。完整绘画目标沿用 1.29.0，未新增生成。技术通过不等于艺术效果通过。

发布时：

1. 确定 GitHub 仓库地址，再将本目录内容推送。不要从私人研究工作区执行 git add 全部。
2. 发布后在干净目录从真实 URL 克隆，再运行本地安装与离线检查，实际看 GitHub 的 README 图片和链接。
3. 如需 skills.sh，核对真实仓库被发现和安装后，再加入实际安装命令、链接与徽章。当前没有远端安装或市场收录证据。
4. Claude marketplace、ClawHub、Tessl 各有单独发布要求，当前未配置也未发布，不宣称兼容这些执行环境。
5. 已补充两例用户认可的历史猫狗案例；下一步继续用新主体和新场景验证艺术迁移，记录实际输入/请求、成图、视觉问题与用户认可；生成数量另行授权。

可继续改进：录制真实从设计到最终出图的演示。当前提供真实认可静帧与历史文件交互回放，明确不是生成工具录屏；不把静态图拼成假流程 GIF。
